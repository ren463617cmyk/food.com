# Spice & Soul — GitHub Pages

This is the original uploaded website, prepared for GitHub Pages.

## Upload
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` to the repository root.
3. Commit to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **GitHub Actions** if available, or **Deploy from a branch → main → / (root)**.
6. Open the GitHub Pages URL shown by GitHub.

The filenames are intentionally lowercase because GitHub Pages is case-sensitive.
